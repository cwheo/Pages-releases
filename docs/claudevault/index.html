ClaudeVault

Claude Code Account Backup / Restore / Switch

About

ClaudeVault backs up and restores the Claude Code login state (.credentials.json plus the account-bound fields of .claude.json) as a single profile file, so you can keep several accounts on one PC and switch between them in one step - handy when one account hits its usage limit.

Requirements

  • Windows 10 / 11
  • Python 3.x on PATH (no external packages - standard library only)
  • Claude Code installed and logged in

Default install folder: C:\HCW\ClaudeVault

Security notice

A saved profile (*.claudevault_json) contains your OAuth access and refresh tokens in plain text - treat it like a password. Do not put it in a cloud-synced folder, do not commit it to a repository, and do not use the same profile on two PCs at the same time (refresh token rotation invalidates one side). If a profile leaks, log out on claude.com and run /login again to issue new tokens. The installer never deletes your profiles, not even on uninstall.
